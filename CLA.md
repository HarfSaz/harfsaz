## How to accept

This Project uses the **Developer Certificate of Origin (DCO)** as the
lightweight mechanism for accepting this CLA. Sign off on every commit:

    git commit -s -m "your message"

This adds a `Signed-off-by: Your Name <your@email>` line, which certifies that
you have the right to submit the contribution and that you agree to this CLA and
to the [DCO](https://developercertificate.org/).

For substantial contributions, the Maintainer may additionally request explicit
written agreement to this CLA.
