# Harfsaz 0.1.0 preview deployment

Deployed 2026-09-13 (Toronto), 2026-09-14 UTC.

- Workspace: https://harfsaz.com/app
- Downloads: https://harfsaz.com/download
- macOS Apple Silicon: https://harfsaz.com/api/download/mac
- Linux ARM64 Debian package: https://harfsaz.com/api/download/linux
- Checksums: https://harfsaz.com/api/download/checksums

macOS is ad hoc signed and unnotarized; no Developer ID certificate was available. Linux requires ARM64 and WebKitGTK 4.1 (Debian 12 / Ubuntu 24.04+). No Intel Mac, x86-64 Linux, or Windows artifact was built for this deployment.

Validation: 73 editor tests, 36 backend tests, TypeScript checks, production Next build, macOS signature and DMG integrity, Linux install/startup, production cloud document save/read/share/revoke, public workspace/health responses, and signed download hashes. Google OAuth start uses the production callback and secure cookie. Full interactive SSO, payment completion, email inbox delivery, and visual browser QA were not performed.

Production uses a fresh PostgreSQL database; development accounts and documents remain local. Stripe is sandbox. Private SMTP handshake and TLS passed without sending mail. Publish SPF/DKIM records from production-dns.md for email authentication. The root domain is deployed; www DNS was still absent at verification.

The backend repository contains Docker and deployment instructions in deploy/README.md. Production secrets are only in protected server environment files, not source or release artifacts.
